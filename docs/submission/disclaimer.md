# Independent project disclaimer

RecoveryOS is an independent hackathon demonstration created for the Razorpay Buildathon AI Revenue
Recovery track. It is not a Razorpay product, is not sponsored or endorsed by Razorpay, and does not
imply a partnership or affiliation.

The interface uses an original RecoveryOS identity and a visually compatible, Razorpay-inspired
merchant-product vocabulary. It does not use the Razorpay logo, wordmark, proprietary illustrations,
copied page layouts, or source assets. “Razorpay Test Mode” and
`RAZORPAY TEST VERIFIED` describe an integration environment or evidence class only.

The project is test/demo software. It must not process live payments or contact real customers.
Any guarded telephony demonstration is restricted to an operator-triggered, server-allowlisted,
pre-consented, team-owned number. RecoveryBench results are synthetic simulations, not measured
merchant performance, financial advice, or a performance guarantee.
